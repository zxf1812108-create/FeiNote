# 飞记 (FeiJi Bullet Notes) - 原生 Android 子弹笔记软件

专为 Android 原生打造的子弹笔记应用，完全离线运行、启动迅速、极简流畅。

## 🛠️ 技术架构

- **编程语言**：100% 原生 Kotlin
- **界面框架**：Jetpack Compose (Material 3)
- **本地存储**：Room 本地 SQLite 数据库 (完全离线，数据永久持久化)
- **构建系统**：Gradle Kotlin DSL (`.gradle.kts`) + Version Catalog (`libs.versions.toml`)
- **CI/CD**：GitHub Actions 在线自动编译工作流 (`.github/workflows/build-apk.yml`)

---

## 📱 核心功能与操作规范

1. **日期流管理**：
   - **左上角日期区域**：显示当前所选日期（格式：`yyyy年MM月dd日 EEEE`），点击弹出原生 `DatePickerDialog`。
   - **日期状态标识**：
     - 当前为今天时显示 **“今天”**。
     - 切换到其他日期后自动变为 **“回到今天”**。
     - 点击“回到今天”立即回到今天，文字变回“今天”。
     - 点击“今天”弹出提示对话框：“是否恢复今天初始数据备份？”

2. **单行折叠与回车新增**：
   - 默认状态下每条笔记单行展示，超过一行自动省略（`maxLines = 1, Ellipsis`）。
   - 点击笔记内容进入编辑模式，展开多行完整内容。
   - 在笔记末尾按回车键（Enter），自动在下方新增一条笔记，并附带当前所选日期的属性。

3. **三态标识符（Bullet Symbol）**：
   - 每条笔记前方具有专属子弹标识：
     - **方框 (☐)**：待办事项
     - **对勾 (☑)**：已完成任务（文字带删除线）
     - **实心圆点 (●)**：记录/想法/日志
   - **点击标识符**：在 `方框` -> `对勾` -> `实心圆点` 之间轮流切换。
   - **长按标识符**：弹出日期选择器修改该笔记所属日期。若修改后的日期与当前展示日期不同，该笔记立即从当前视图移出。

4. **拖拽排序**：
   - 按住笔记内容不放，可直接上下拖动改变笔记在该日内的先后顺序，顺序实时持久化至 Room 数据库。

5. **回收站与清空**：
   - 顶部右上角常驻垃圾桶图标（不显示数量角标）。
   - 点击展开回收站弹窗，支持单条笔记恢复与单条彻底删除。
   - 顶部“回收站”标题右侧与关闭按钮“×”之间设有 **“全部删除”** 按钮，点击二次确认后彻底清空回收站。

6. **每日自动备份与恢复**：
   - **每日自动备份**：每天首次启动应用时，后台自动读取全量笔记并导出至系统 `Download/飞记每日自动备份.json` 文件。自动覆盖前一日文件，确保目录内仅保留一份最新镜像。
   - **点击今天恢复**：点击顶部“今天”标识，弹出恢复询问对话框，点击“是”即可从 `Download` 目录中完整恢复数据。

## 🚀 编译与运行方法

### 方式一：GitHub Actions 在线自动编译 APK (无需配置本地环境)
1. 将本项目推送到 GitHub 仓库（`git push origin main`）。
2. GitHub 会自动触发 `.github/workflows/build-apk.yml` 工作流。
3. 工作流运行完成后，进入 GitHub 仓库的 **Actions** -> **Build Android Debug APK**，在 **Artifacts** 区域即可一键下载已编译好的 `app-debug.apk` 安装到手机。

### 方式二：Android Studio 本地编译
1. 打开 **Android Studio** (推荐 Hedgehog / Iguana / Ladybug 或更高版本)。
2. 选择 **Open** 打开本工程根目录。
3. 等待 Gradle 同步完成后，点击运行按钮或在终端执行：
   ```bash
   ./gradlew assembleDebug
   ```
4. 编译生成的 APK 位于：
   `app/build/outputs/apk/debug/app-debug.apk`
