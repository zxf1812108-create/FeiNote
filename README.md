# 飞记（FeiNote）使用说明

飞记是一款简洁的安卓子弹笔记软件，主要用于记录日常事项、待办任务和随手笔记。

软件以日期为单位管理笔记，支持任务状态标记、拖动排序、修改日期、回收站和每日自动备份。

## 一、添加笔记

1. 打开飞记，默认显示今天的笔记。
2. 如果当天还没有笔记，点击屏幕中央的“点击此处开始记录”。
3. 输入笔记内容。
4. 按键盘上的回车键或“下一项”键，即可在当前笔记下方新建一条笔记。
5. 继续输入，即可连续记录多条笔记。

每条笔记会自动关联当前页面显示的日期。

## 二、查看和修改笔记

**查看笔记**

平时，每条笔记只显示一行文字。如果内容较长，超出部分会自动省略，保持列表简洁。

**修改笔记**

1. 点击需要修改的笔记文字。
2. 笔记进入编辑状态，显示完整内容。
3. 光标自动定位在文字末尾，可以直接继续输入。
4. 也可以点击文字中的任意位置，修改已有内容。
5. 编辑完成后，点击笔记以外的空白区域，即可退出编辑状态。

修改内容会自动保存，无须点击保存按钮。

注意：编辑时按回车键会创建一条新笔记，而不是在原笔记中换行。

## 三、使用笔记状态标记

每条笔记左侧都有一个状态标记。

点击标记，可以依次切换三种状态：

| 标记 | 含义 | 使用建议 |
|---|---|---|
| □ | 待办事项 | 尚未完成的任务 |
| ✓ | 已完成 | 已经办完的任务 |
| ● | 普通笔记 | 随手记录、备忘信息 |

操作方法：

1. 点击笔记左侧的标记。
2. 标记自动切换到下一种状态。
3. 再次点击，继续切换。
4. 三种状态循环切换。

当笔记标记为已完成时，文字会显示删除线，便于区分已完成和未完成的任务。

## 四、调整笔记顺序

可以通过拖动调整同一天笔记的排列顺序。

1. 用手指长按需要移动的笔记文字。
2. 保持手指按住屏幕。
3. 向上或向下拖动笔记。
4. 其他笔记会移动，为被拖动的笔记腾出位置。
5. 将笔记移动到合适位置后松开手指。

新的排列顺序会自动保存，下次打开仍然保持调整后的顺序。

注意：应长按笔记的文字区域，而不是左侧状态标记。左侧标记的长按操作用于修改日期。

## 五、查看不同日期的笔记

软件左上角显示当前查看的日期。

**查看过去或未来的笔记**

1. 点击左上角的日期。
2. 在弹出的日期选择器中选择目标日期。
3. 确认后，页面显示该日期对应的笔记。

**返回今天**

查看其他日期时，日期右侧会显示“回到今天”。

点击“回到今天”，即可返回当天的笔记列表。

在历史日期或未来日期的页面中添加笔记，新笔记会归入当前选中的日期。

## 六、将笔记移动到其他日期

如果某项任务需要延期，或者希望将笔记归入其他日期，可以直接修改笔记日期。

1. 找到需要移动的笔记。
2. 长按笔记左侧的状态标记（□、✓或●）。
3. 在弹出的日期选择器中选择新日期。
4. 确认后，笔记会归入指定日期。

如果新日期与当前日期不同，该笔记会从当前列表中消失。

需要查看时，点击左上角日期，切换到目标日期即可。

这一功能适合将未完成任务延后处理。

## 七、删除和恢复笔记

**删除笔记**

1. 点击需要删除的笔记文字，进入编辑状态。
2. 点击笔记右侧的垃圾桶图标。
3. 笔记会移入回收站。

删除后的笔记不会立即永久清除，可以从回收站恢复。

**恢复笔记**

1. 点击页面右上角的回收站图标。
2. 找到需要恢复的笔记。
3. 点击对应的恢复操作。
4. 笔记会恢复到原来所属的日期。

**清理回收站**

回收站提供“删除一天前”功能。

点击后，可以永久删除昨天及更早移入回收站的笔记。

例如，今天是11月10日：

- 11月10日删除的笔记：保留。
- 11月9日删除的笔记：可以清除。
- 11月8日及更早删除的笔记：可以清除。

这里按照笔记进入回收站的日期计算，而不是笔记内容所属的日期。

注意：永久删除后的笔记不能再通过回收站恢复。

## 八、自动备份笔记

飞记具有每日自动备份功能。

软件会在当天首次启动时检查备份情况，并将笔记数据备份到手机的 Download（下载）文件夹。

备份文件名称为：

`飞记每日自动备份.json`

该文件用于保存笔记数据，方便需要时恢复。

**恢复备份**

1. 返回今天的笔记页面。
2. 点击日期右侧的“今天”标签。
3. 软件弹出“恢复数据备份”确认窗口。
4. 点击“是”，软件会尝试读取 Download 文件夹中的备份文件。
5. 根据软件提示确认恢复结果。

注意：恢复备份可能改变当前笔记数据。建议在恢复之前妥善保留现有数据和备份文件。

## 九、常用操作速查

| 想要完成的操作 | 操作方法 |
|---|---|
| 新建笔记 | 空白页面点击中央提示，或编辑时按回车 |
| 查看完整笔记 | 点击笔记文字 |
| 修改笔记 | 点击文字后直接编辑 |
| 保存修改 | 点击笔记外的空白区域 |
| 标记完成 | 点击左侧状态标记，切换到✓ |
| 改为普通笔记 | 点击左侧标记，切换到● |
| 调整排列顺序 | 长按文字并上下拖动 |
| 修改笔记日期 | 长按左侧状态标记 |
| 查看其他日期 | 点击左上角日期 |
| 返回今天 | 点击“回到今天” |
| 删除笔记 | 进入编辑状态，点击右侧垃圾桶 |
| 恢复笔记 | 打开右上角回收站，选择恢复 |
| 清理旧笔记 | 回收站中点击“删除一天前” |
| 恢复备份 | 在今天的页面点击“今天”标签 |

## 十、使用建议

飞记可以采用简单的每日记录方式：

早晨，将当天需要完成的事项逐条输入，使用□标记。

白天，完成一项任务就将□切换为✓。遇到需要记录的信息，可以使用●标记。

晚上，检查当天未完成的事项。对于需要延后处理的任务，长按左侧标记，将笔记移动到明天或其他日期。

通过这种方式，可以把飞记作为一个轻量的日常任务清单和个人备忘录，不必建立复杂的分类体系。
